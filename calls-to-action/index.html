Community Calls to Action

When one community needs help, we respond together. This page features current needs that M1U has reviewed, each for a limited period.

How a call to action works

  1. M1U reviews the need

    We confirm the need with the organization or community involved before anything is published.

  2. It is featured for a limited time

    Each call to action runs for a set period, so this page reflects what is needed now.

  3. You are directed to an approved pathway

    Support links go only to a donation or support pathway that has been verified.

  4. Results are documented

    Once verified, what came of each effort can be recorded under Our Impact.
